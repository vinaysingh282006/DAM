1. Dual-Core FreeRTOS Architecture & Zero-Block Determinism
Why doesn't the web server freeze the emergency gate?
The ESP32 runs a dual-core Xtensa 32-bit LX6 processor. Core 1 runs the real-time sensor loop, conductivity probe debounce, ultrasonic pulse timing, and emergency interlock FSM without any blocking delays. Core 0 runs the asynchronous HTTP/WebSocket server (ESPAsyncWebServer). Even if a Wi-Fi client disconnects or floods HTTP requests, Core 1 operates deterministically with zero jitter.
2. Water Level Sensing: 4-Level Conductivity vs Ultrasonic Sensor
Why use both conductivity wires and sonar?
Conductivity probes provide an infallible hardware discrete threshold (Low, Mid, High, Danger) immune to acoustic surface ripples, steam, or floating debris. The HC-SR04 sonar transducer provides continuous millimetric distance telemetry and functions as a forward-facing obstacle & intrusion lockout interlock before opening heavy radial gates.
3. Spillway Gate Hydraulic Equation & Discharge Curve
The spillway obeys the standard weir discharge relation: Q = C_d · L · H^(3/2) modulated by the radial tainter opening percentage θ / 100. When reservoir water touches the top probe (Danger P4), the FSM triggers a staged servo trapezoidal ramp profile to avoid downstream surge wave erosion in the stilling basin.
4. Fail-Safe Interlock Matrix & Sensor Fault Isolation
If the ultrasonic sensor reports < 40 cm (floating debris or maintenance boat in the spillway mouth), the servo gate is immediately locked in its current position with an audible alarm. If an open-circuit fault occurs (probe wire disconnected while higher probes are wet), the firmware detects an illogical state and falls back to ultrasonic echo depth.
